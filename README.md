# 🩺 Breast Cancer Prediction ML App

## 📌 Project Overview
The Breast Cancer Prediction ML App is a Machine Learning-based application developed using Python to predict whether a breast tumor is **Benign (Non-Cancerous)** or **Malignant (Cancerous)** based on medical diagnostic features.

The application uses machine learning algorithms to analyze input data and generate predictions through an interactive user interface.

## 🎯 Project Objective
The main objective of this project is to demonstrate how Machine Learning can be used to analyze breast cancer diagnostic data and support research and educational purposes through automated predictions.

## 🔍 How It Works
1. The user enters the required diagnostic features.
2. The application processes the input data.
3. The trained Machine Learning model analyzes the features.
4. The model generates a prediction.
5. The application displays the predicted category.

## 📊 Prediction Categories
- **Benign:** Indicates a non-cancerous tumor prediction.
- **Malignant:** Indicates a cancerous tumor prediction.
